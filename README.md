# С Днём Рождения, Машуля! ♥

Пиксельный ретро-сайт-поздравление: листаешь 19 фоток → за каждую в панель сверху
прилетает сердечко → в финале все 19 сердечек слетаются в одно большое, и под ним
появляется поздравление.

## Что где лежит

```
index.html      разметка (интро, финал)
css/style.css   вся пиксельная стилистика
js/main.js      логика + ВСЕ ТЕКСТЫ (блок CONFIG в самом верху файла)
photos/         сюда 19 фоток: 01.jpg … 19.jpg
```

## Что можно поменять

Открой `js/main.js` — сверху блок `CONFIG`:

- `captions` — 19 подписей под фотками;
- `message` — текст поздравления;
- `signature` — подпись;
- `photoCount` — если фоток будет не 19.

Цвета — в `css/style.css`, самый верх (`:root`).

## Фотки

Все 19 уже лежат в `photos/` (`01.jpg` … `19.jpg`). Рамка сама подстраивается
под пропорции каждой фотки, поэтому вертикальные и горизонтальные не обрезаются.

Заменить любую — просто положить файл с тем же именем.
Подробнее про имена и форматы — в `photos/README.md`.

## Как посмотреть локально

Просто открыть `index.html` двойным кликом. Или, если хочется «по-честному»:

```bash
cd ~/Desktop/bday-mashulya && python3 -m http.server 8000
```

и открыть http://localhost:8000

## Публикация на GitHub Pages

1. Создай на GitHub новый **публичный** репозиторий, например `bday`.
2. В терминале, из папки проекта:

```bash
cd ~/Desktop/bday-mashulya && git init && git add -A && git commit -m "birthday site"
```

```bash
cd ~/Desktop/bday-mashulya && git branch -M main && git remote add origin https://github.com/ТВОЙ_ЛОГИН/bday.git && git push -u origin main
```

3. На GitHub: репозиторий → **Settings** → **Pages** → в разделе *Build and deployment*
   выбрать **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет по адресу:
   `https://ТВОЙ_ЛОГИН.github.io/bday/`

Обновить сайт после правок:

```bash
cd ~/Desktop/bday-mashulya && git add -A && git commit -m "update" && git push
```

> Репозиторий должен быть публичным — иначе Pages на бесплатном тарифе не включится.
> И да: фотки в публичном репозитории видны всем, у кого есть ссылка.
> Если это не ок — можно сделать приватный репозиторий на платном тарифе
> или залить фотки в другое место.

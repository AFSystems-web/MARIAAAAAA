# Сюда кладём фотки

19 штук, названия строго такие:

```
01.jpg  02.jpg  03.jpg  ...  09.jpg  10.jpg  ...  19.jpg
```

Важно:
- **двузначные номера** — `01`, а не `1`;
- расширение может быть `.jpg`, `.jpeg`, `.png` или `.webp` — скрипт сам подберёт;
- квадратные фотки смотрятся лучше всего (рамка квадратная, некруглые фото просто обрежутся по центру);
- перед заливкой лучше сжать фотки (например до ~1200px по стороне), чтобы сайт быстро открывался на телефоне.

Пока фотки не добавлены — вместо них показывается пиксельная заглушка. Это нормально.
